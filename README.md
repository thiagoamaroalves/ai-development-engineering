## Status

Os dez findings identificados na auditoria inicial foram remediados e aprovados pelo usuário em 2026-08-31. A auditoria inicial permanece preservada como registro histórico.

## Fonte canônica de skills

`skills/` é a única fonte semântica canônica das skills e contratos compartilhados deste projeto. `.codex/skills/` é apenas um espelho gerado para compatibilidade com o Codex; skills exclusivas do Codex são preservadas, mas não podem substituir a fonte canônica. Valide o espelho com `npm run verify:skill-mirror` após alterações.
